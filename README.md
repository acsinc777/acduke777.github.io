## Projects
### D&D Beginner Species Database
This project was coded using Java with SQLite database integration. What it aims to do is act as a simple program that allows for a new player of D&D 5th Edition to gain a simplistic overview of each playable Species option that can be chosen at character creation. D&D is infamously a complex game to get into, requiring some handholding and some waving of the rules in lieu of ensuring a new player has fun. This program allows a player to be able to interact with a Species, both its lore and abilities, in a way adjacent to the actual content of the game that allows them to slowly get used to the basis of the game. Each Species laid out was simplified in a way that acts as a base building block of knowledge, with the actual content and mechanics of a player option able to be integrated seemlessly when the player is ready.
### Rolodex Prototype
This project was coded using Java with SQLite database integration. Done as a final for a class, this project aims to save, store and recall contact information for your own use. It has three kinds of contact types (friend, family and business) with relevant fields to be filled out. Using SQLite, any contacts you put in are saved until you delete them or edit them as you seem fit.
### Adieu, Madeline
This project is a passion project of a friend of mine. It is being made in RPGMaker MV, which has a big emphasis on plug-ins written in javascript. The game is about Isolde, a woman on her own personal death march as she aims to travel across multiple countries to mourn the loss of her childhood love, of which she had a complicated relationship with. Armed with nothing but a simple sword and her horse, Pavel, she will travel and fight many frightening enemies and new friends in a dark fantasy setting that was inspired by the likes of The Legend of Zelda: A Link to the Past, Jim Henson's Dark Crystal and Fear & Hunger. I work as a concept artist for the game, making enemy designs and sketching out basic NPCs. I have also been responsible for designing two integral party members of the game. It is unknown if they will be used in the state that they are currently designed. All of my art is considered 'not final' until my friend decides to integrate it at his own descretion, of which a substantial amount of enemy designs have already.
